# slop-stop

Скилл для редактирования технических текстов на русском и английском. Убирает канцелярит, пустые вступления и другие шаблоны ИИ-текста.
Подходит для README, документации, спецификаций, описаний коммитов и запросов на слияние, а также записей об архитектурных решениях (ADR).

Правила требуют сохранять факты, числа, оговорки, причинные связи и технические термины. Если исходник не содержит подробностей, скилл запрещает придумывать их.

## Пример

До:

> Важно отметить, что после выхода версии 2.4 количество ошибок таймаута, как правило, снижается примерно на 30%.

После:

> После выхода версии 2.4 количество ошибок таймаута, как правило, снижается примерно на 30%.

Скилл убирает пустое вступление. Оговорки «как правило» и «примерно» сохраняют точность исходного утверждения.
Другие примеры собраны в [references/examples.md](references/examples.md).

## Установка в Claude Code

Для работы нужны Claude Code и файлы скилла. Для установки через командную строку нужен Git.

Папка назначения должна отсутствовать или быть пустой.

Linux и macOS:

```bash
git clone https://github.com/brainfrog/slop-stop.git ~/.claude/skills/slop-stop
```

Windows, PowerShell:

```powershell
git clone https://github.com/brainfrog/slop-stop.git "$env:USERPROFILE/.claude/skills/slop-stop"
```

Такой скилл доступен во всех локальных проектах пользователя.
Для установки в один проект скопируйте `SKILL.md` и папку `references/` в `.claude/skills/slop-stop/` внутри проекта.
Сохраните структуру папок: скилл читает справочники по относительным путям.
Пути установки описаны в [документации Claude Code](https://code.claude.com/docs/en/skills#choose-where-skills-load).

## Использование

Вызовите скилл в Claude Code:

```text
/slop-stop Отредактируй README.md: убери канцелярит и шаблонные фразы.
```

Или попросите разобрать текст:

```text
/slop-stop Проверь, звучит ли этот абзац как ИИ-текст. Объясни замечания, но не переписывай.
```

Claude Code также может выбрать скилл по описанию задачи. Прямой вызов и автоматический выбор описаны в [документации](https://code.claude.com/docs/en/skills).

| Режим | Результат |
|---|---|
| Чат | Итоговый текст и список изменений |
| Файл | Итоговый текст в файле, список изменений в чате |
| Часть другой задачи | Готовый текст; предупреждения и сведения об удалённом содержании передаются основной задаче отдельно |
| Разбор | До пяти замечаний с цитатами и названиями шаблонов, затем оценка стиля; исходный текст остаётся прежним |

Разбор оценивает стиль текста. Скилл не определяет автора и не выдаёт «вероятность ИИ».
Обычные ответы в чате скилл редактирует только по инструкции проекта.
Если вы дадите образец своего письма, скилл будет учитывать лексику, длину предложений и пунктуацию образца.

## Проверка изменений

После правок запустите из корня репозитория:

```bash
python -I scripts/check.py
```

Нужен Python 3. Если команда `python` запускает другую версию, используйте `python3`.
Скрипт проверяет метаданные, ссылки, примеры и согласованность правил. Если GNU grep отсутствует, соответствующую проверку скрипт пропускает с предупреждением.

После изменения `scripts/check.py` запустите тесты самого скрипта. Для них нужны Bash и GNU sed:

```bash
bash scripts/test_check.sh
```

После изменения `SKILL.md` или справочников проверьте поведение модели:

```bash
python -I scripts/eval.py
```

Этот запуск требует настроенного Claude Code CLI и выполняет платные обращения к модели. Скрипт выводит стоимость запуска.
Порядок проверки и параметры запуска описаны в [MAINTAINING.md](MAINTAINING.md).
